# Slikk | Premium Home Decor Quick-Commerce

A high-fidelity, quick-commerce platform for curated home decor, furniture, and aesthetic living essentials. Built with Next.js 15, React 19, and Tailwind CSS v4.

## Features

- **Hyperlocal Discovery**: Real-time inventory from nearby hubs.
- **Aesthetic Curation**: Curated collections for modern workspaces and homes.
- **60-Minute Delivery**: Ultra-fast fulfillment tracking.
- **Premium UI**: Editorial-style grid layouts and smooth animations.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment on Render

This project is pre-configured for deployment on **Render** using the included `render.yaml` blueprint.

1. Connect your GitHub repository to Render.
2. Render will automatically detect the `render.yaml` file and configure the Web Service.
3. The build and start commands are already set:
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm run start`

Alternatively, you can manually create a **Web Service** on Render and point it to this repository.
